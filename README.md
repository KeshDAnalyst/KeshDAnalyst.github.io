# KeshDAnalyst Portfolio

Redesigned as a polished dark analytics portfolio inspired by the supplied reference design.

### Design direction
- Deep navy/teal background
- Bright aqua/teal accents
- Large bold name typography
- Glassy/teal project and skill cards
- No profile photo
- No dashboard screenshots
- Dedicated Teaching & Analytics Framework section
- Easy-to-update Certifications section

### GitHub Pages
Upload the contents of this folder to the root of your GitHub repository, keeping the `assets` folder structure intact. Then deploy from `main` / `(root)` under **Settings → Pages**.

### Future updates
You can replace the CV, add certificates under `assets/`, add more project cards, or edit the text without rebuilding the whole website.
